This reading list brings together [mohanson’s](https://talk.nervos.org/u/mohanson/activity/topics) CKB-VM deep dives on Nervos Talk. It covers ten posts published between June 11 and August 7, 2026, checked on November 10, 2026.

Start with the [CKB-VM overview](/docs/ckb-fundamentals/ckb-vm) for background. All ten articles are adapted in these docs with their full text, examples, and source attribution.

:::note CFI status

The [CFI article](/docs/ckb-fundamentals/ckb-vm-internals/cfi-extension) describes a proposed extension. As of November 10, 2026, the [implementation PR](https://github.com/nervosnetwork/ckb-vm/pull/492) remains open and is titled “[WIP] Implement CFI.” Treat this article as design material, not as documentation of an activated CKB network feature. W^X page permissions alone do not prevent ROP/JOP attacks.

:::

## Reading by Topic

- **Execution and performance:** read the decoder article, then the assembly executor, macro-op fusion, and B extension articles.
- **State and resource limits:** read Snapshot V1, Snapshot V2, and Cycles together.
- **Memory and security:** read the memory model article before the CFI design article.
- **Cross-script calls:** read Spawn alongside the [VM Version History](/docs/script/vm-version) and [Meepo hard fork history](/docs/history-and-hard-forks/ckb-hard-fork-history#meepo-hardfork).

The articles describe different implementation layers. Check the VM version and hard fork documentation when choosing features for a deployed script; publication dates do not indicate network activation dates.
